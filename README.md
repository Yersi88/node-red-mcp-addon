# Node-RED MCP Add-on

Runs [ziv-daniel/node-red-mcp](https://github.com/ziv-daniel/node-red-mcp) as a
Home Assistant add-on, exposing Node-RED flow management to AI agents over the
Model Context Protocol.

## Install

Add this repository to Home Assistant:

1. **Settings → Add-ons → Add-on Store**
2. Click **⋮** (top-right) → **Repositories**
3. Add the repository URL (or a local path like `/addons/node-red-mcp-addon`)
4. Install **Node-RED MCP Server**, configure, and start

## Configuration

See [`node-red-mcp/README.md`](node-red-mcp/README.md) for the full option
reference and agent connection instructions.
